# Runners Quest
Runners Quest is a personal running application that combines run tracking, goals, and challenges with classic arcade and RPG-inspired progression.

The goal is to make running feel more like a game: complete quests, build attributes, earn rewards, and progress through increasingly difficult challenges while maintaining a useful running log underneath it all.

# Tech Stack
## Frontend
- React
- TypeScript
- Vite
- PixiJS

React owns the application. PixiJS owns the arcade surfaces.

## Backend
- Go

## Frontend development

Install dependencies:

```sh
npm install
```

Run the development server:

```sh
npm run dev
```

Build the frontend:

```sh
npm run build
```

There is no automated test suite yet. The production build is the currently available validation check.
