# Runners Quest Design

Runners Quest (RQ) is a gamified running log that makes logging miles fun!

Runners can record runs, manage shoes, and undertake quests and challenges of all kinds.

## Overall aesthetic and vibe

The vibe is 90's _Runner's World_ teleported into an arcade game cabinet. It should feel fun and
retro. The vibe should make the mundane (logging running miles) feel awesome and heroic.

## Title screen

The title screen gives RQ a retro arcade feel. It should feel classic and have elements that
change over time so the user will want to return to see what's new. (E.g., "Wonder what Dave will
do next!")

The user interacts with the title screen (such as clicking on the _Press Start_ element) to advance
to the main screen.

## Main screen

The main screen enables the core functions of RQ, plus a map-based visualization or the runner's progress and achievements.

The main screen is composed of several panels.

### Runner panel

Contents:
- Runner avatar. Selectable pixel art character.
- Runner name. E.g., "Adam" or "Beth".
- Shoes. Lists two most recent shoes with miles. Button to enable shoe management (add, delete, retire, adjust miles).
- Settings button. Enables runner specific settings, such as language, units (metric or imperial), week starts on, etc.

### Log panel

Displays week by week view with monthly and yearly totals.

Runners add and edit log entries to track their runs. Runners can add much or as little information
as they like (the minimum being "I ran"). Totals and progress are calculated automatically.

Run items:
- date
- Run/walk completed
- time
- distance
- elevation gain
- shoes
- perceived effort
- terrain: road, treadmill, trail, track

Calculated automatically:
- pace
- distance totals
- time totals
- shoe miles
